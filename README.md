# LeaveFlowApp · 1.1

这是一个独立、可离线使用的安卓界面原型，按参考截图及原版界面资源制作，适配小米 15 Pro 的竖屏显示。

桌面名称为“易班”，独立包名为 `dev.h4ze.leaveflow`。这是本地自定义原型，并非官方客户端；显示的记录与审批状态由本机编辑，不代表学校系统中的真实审批结果。

当前版本为 `1.1`，内部版本号为 `2`。安装包见仓库的 Releases 页面。

## 使用流程

1. 首页只开放“请销假”入口。
2. 列表页可打开已有申请，也可通过底部“请假申请”新增。
3. 详情页支持两种状态：
   - 审批通过：绿色双圆环印章，五角星匀速环绕。
   - 结束请假：原版灰色状态图标，完全静态。

状态印章固定悬浮在详情内容区域右上角，不会随长页面滚动。

个人信息默认收起，姓名后显示括号中的学号。展开后姓名不带学号，学号显示在个人信息第一行。

“转发审批表单”固定在详情底部，可打开单独页面。有效期读取设备当前时间并自动延后七天；二维码、链接和生成操作目前为占位，待后续完善。

## 秘密入口

在详情页顶部蓝色栏的标题上连续点击 **5 次**，进入“自定义管理”。入口本身没有可见按钮。

自定义管理支持：

- 新增、编辑、删除请假记录；
- 修改详情标题、三个分区标题；
- 修改申请人、时间、原因、地址、联系人、附件文字、销假人和审批进度；
- 切换动态“审批通过”或静态“结束请假”状态。
- 选择、替换或删除申请书与证明材料；
- 直接在签名板上手写签名并保存。

图片附件在详情页显示缩略图，点击可全屏预览；PDF、Word、文本等文件点击后使用手机上对应的预览应用打开。

所有数据仅保存在本机应用私有存储中，不联网、不上传。

## 构建

需要 JDK 17、Android SDK 36 和可用的 Android 构建工具。使用 `ANDROID_HOME` 指定 SDK，或在不提交的 `local.properties` 中配置 `sdk.dir`。

```bash
./gradlew :app:assembleDebug
```

调试 APK 输出到：

`app/build/outputs/apk/debug/app-debug.apk`

Release 中提供的是调试签名安装包。源码不包含签名密钥、本机记录、上传的附件、原始 APK 或抓取的页面资料。界面中的参考图形资源用于该原型，仓库未附加开源授权。
